# 手机安装教程（小芽家庭学习 · 手机版）

正式地址：**https://xiaoya-learning.app.workbuddy.host/**

不需要安装包、不需要应用商店，用浏览器打开即可使用；按下面的步骤可以把它装到手机桌面，
打开后是全屏窗口，和普通 App 几乎没有区别。

---

## 一、iPhone / iPad（Safari）

1. 用 **Safari** 打开 `https://xiaoya-learning.app.workbuddy.host/`
   （必须是 Safari，微信内置浏览器不行）。
2. 点屏幕底部中间的 **分享按钮**（方框 + 向上箭头）。
3. 在菜单里向下滑，选择 **「添加到主屏幕」**。
4. 名称会显示为「小芽学习」，点右上角 **「添加」**。
5. 回到桌面，会出现小芽的绿色图标，点它即可全屏打开。

> 第一次打开后，建议先联网打开一次「今日课程」，让课程和语音缓存下来，之后断网也能学。

---

## 二、安卓（Chrome / Edge）

1. 用 **Chrome** 打开 `https://xiaoya-learning.app.workbuddy.host/`
2. 首次打开时，页面底部一般会弹出 **「添加到主屏幕」** 提示，直接点它；
   如果没有弹出：
   - 点右上角 **⋮** 菜单 → **「安装应用」** 或 **「添加到主屏幕」**。
3. 确认后桌面会出现「小芽学习」图标。

> 华为 / 小米 / OPPO / vivo 自带浏览器路径类似：菜单 →「添加到桌面」。
> 建议优先用 Chrome 或 Edge，兼容性最好。

---

## 三、Windows 电脑浏览器

- **Edge**：地址栏右侧会出现「安装」图标，点它即可装成桌面应用；或菜单 →「应用」→「安装此站点为应用」。
- **Chrome**：地址栏右侧「安装」图标，或菜单 →「投放、保存和分享」→「安装页面为应用」。

---

## 四、每天怎么用

1. 打开桌面的「小芽学习」图标。
2. 点 **「孩子入口」** → 选学科（汉字 / 英语 / 数学）→ 选学习方式 → 开始。
3. 学完后记录会自动保存在手机上。
4. 家长要做同步时：点 **「家长入口」** → 输入家长密码 → 登录 → 点两个按钮。

---

## 五、离线能用吗？

可以：

- **应用可以离线打开**：打开过一次之后，断网也能进入。
- **已经学过的课程可以离线学习**：课程包与用到的语音会被缓存。
- **离线答题记录照样保存**，回到有网络时点「上传学习记录」即可。

没能离线完成的部分（需要联网）：

- 「上传学习记录」「更新学习课程」这两个按钮必须联网。
- 手机从来没有下载过的新课程，需要联网点一次「更新学习课程」。

## 六、常见问题

| 现象 | 处理办法 |
| --- | --- |
| 微信里打开找不到「添加到主屏幕」 | 换成 Safari / Chrome 打开，微信内置浏览器不支持安装。 |
| iPhone 上没有声音 | 先点一下屏幕任意位置（系统要求由触摸触发音频），再点「再听一次题目」。 |
| 安卓上没有声音 | 确认手机没有静音、媒体音量为 0；部分机型需要先点一次屏幕。 |
| 更新后记录会不会丢 | 不会。课程更新只替换课程，本地记录和未上传记录都保留。 |
| 换手机怎么办 | 旧手机：家长管理 →「设置与备份」→「导出备份 JSON」；新手机：同一账号登录 →「从备份文件恢复」。 |
| 想清空本机记录 | 家长管理 →「设置与备份」→「清空本机记录」，会二次确认；建议先导出备份。 |
