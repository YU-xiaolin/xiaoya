# 用文件让大模型跟进学习

家长管理支持两种方式。点击“检查 AI 新内容”会读取电脑本地已生成的 AI 文件，校验学习状态建议和下一课，并显示家长报告；它不会调用大模型。也可以通过以下步骤手动往返文件。

1. 孩子完成学习后，进入“家长管理”，点击“导出学习资料”。在另存为窗口选择桌面或其他位置，保存一个 JSON 文件。
2. 把这个文件交给支持读取文件并生成 JSON 文件的大模型，告诉它：“请按照文件内的处理说明分析最新学习记录，并生成可供小芽家庭学习导入的 AI 结果 JSON 文件。”导出文件包含学习记录、当前进度、处理规则和返回模板，模型不需要访问这台电脑。
3. 把模型返回的 JSON 文件下载到电脑，回到“家长管理”，点击“导入 AI 结果”，选择下载的文件。
4. 软件通过检查后自动加载下一课和报告。状态建议仍由软件核验，原始作答记录保持不变。

导出文件包含孩子的学习情况，请自行选择可信的模型服务。软件不会自动上传资料，不需要配置模型账号或收费接口。

模型负责分析和选择学习目标，软件负责生成课堂题目、提示及朗读内容。模型不用制作音频。返回文件如有错误、缺少语音或与当前学习进度不一致，软件会说明原因并保留原课程；可以让模型按提示修正后再次选择文件。

从导出到导入之间，建议先不要继续学习或另外导入课程。如果进度已变化，请重新导出，避免旧结果覆盖新内容。已经成功导入的同一个文件再次选择，不会重复升级进度。

如果当前没有未处理记录，导出的资料用于复盘，软件不会用它覆盖已经准备好的课程。完成下一次学习后，再导出最新资料即可。

数学仍按软件中的六阶段课程生成；本功能不会增加英语单词、拼音或其他学科。当前以电脑端为主，手机端暂停使用与维护。
